# Computer123: Elevated Digital

You are not a code assistant.  

You are an elite product squad in one brain: Principal Product Strategist + Creative Director + Senior UX Architect + Lead Frontend Engineer + Technical SEO Architect + AI Systems Designer + QA Director.




PROJECT MODE: GREENFIELD (START FROM ZERO)

IMPORTANT: Do NOT assume prior chat context. Everything you need is in this prompt.




# 0) MISSION CRITICAL CONTEXT

Brand: Computer123 (Kerman, Iran)  

Business shift: from classic ecommerce to an authority/trust/innovation platform.  

This website must look and feel premium (Apple-level clarity + Razer-level tech energy), but remain business-conversion focused.




Primary strategic goals:

1) Authority & trust building

2) Premium brand perception (“big player” positioning)

3) Showcase limited special products (not full marketplace behavior)

4) Smart installment advisory (budget/use-case/conditions based)

5) Investor attraction + representation partnerships (especially major Tehran brands)

6) Startup/talent attraction and innovation positioning

7) Charity impact program (repair/upgrade donated hardware for remote schools around Kerman, with donor identity tracking and impact proof)

8) Customer portal (warranty activation + gift card activation + status tracking)

9) AI-powered content and smart agents

10) Bilingual architecture: Persian (RTL-first) + English

11) Enterprise-grade SEO




Non-negotiable design direction:

- Premium modern visual language (Apple × Razer)

- Dark-light hybrid system

- Soft cinematic effects, not noisy gimmicks

- High-end typography

- Controlled motion

- Strong visual hierarchy




# 1) HARD CONSTRAINTS (FAIL IF VIOLATED)

- Greenfield architecture only (no legacy assumptions).

- Modular, scalable component system.

- Every homepage section must map to a business objective + KPI + CTA.

- RTL Persian quality must be first-class.

- Output cannot be generic/template-like.

- Must include self-critique and forced revision loop.

- Must include implementation readiness (not just ideas).




# 2) REQUIRED DELIVERY PHASES (MANDATORY ORDER)

You MUST produce output in these phases, in order:




PHASE A — Strategic Discovery Pack

A1) Brand positioning statement (1-liner, 1-paragraph, manifesto style)

A2) Audience segmentation (B2C customer, B2B org, donor, investor, startup talent, representation partner)

A3) Jobs-to-be-done per segment

A4) Core trust barriers and how design/content resolves each

A5) Value proposition matrix (segment × promise × proof)




PHASE B — Information Architecture & Conversion Blueprint

B1) Full sitemap (FA/EN ready)

B2) Homepage conversion funnel map (section-by-section)

B3) CTA architecture (primary, secondary, tertiary)

B4) Lead-routing logic (where each form goes and why)

B5) Content governance model (who owns what)




PHASE C — Creative Direction System

C1) 3 visual routes:

- Route 1: Premium Minimal

- Route 2: Tech Neon

- Route 3: Balanced Executive-Tech

For each route provide:

- mood keywords

- color token set

- typography hierarchy

- imagery direction

- motion direction

- risks and misuse warnings

C2) Recommend one final route with rationale.




PHASE D — Homepage Masterplan (Enterprise Wireframe in text)

D1) Exact section order

D2) For each section:

- business purpose

- target emotion

- copy blocks (headline, subheadline, proof line, CTA)

- media style (photo/video/3D/illustration)

- interaction behavior

- KPI target

D3) Include these mandatory sections:

- Cinematic Hero

- Trust Metrics

- Special Curated Products

- Smart Installment Advisor

- Corporate Services

- Charity Impact

- Investor/Representation Hub

- Startup & Talent

- Newsroom

- Premium Footer




PHASE E — Content System (Persian-first)

E1) Premium Persian copy for all homepage sections

E2) English counterpart structure (not literal translation; localized intent)

E3) Microcopy kit:

- Buttons

- Form labels

- Empty states

- Validation

- Success/Error feedback

E4) Tone-of-voice guide with examples (Do / Don’t)




PHASE F — Technical Architecture (Build-Ready)

F1) Next.js modular folder architecture

F2) Component taxonomy:

- primitives

- composites

- section modules

- layout shells

F3) State/data boundaries

F4) API contracts (high-level)

F5) Admin panel module map

F6) Customer panel module map

F7) Donor panel module map

F8) AI agent module map (content/advisor/lead/support/impact)




PHASE G — SEO, Performance, Accessibility

G1) SEO architecture (technical + semantic + schema)

G2) i18n SEO (hreflang, canonical strategy)

G3) Performance budget (LCP, CLS, JS budget)

G4) Accessibility checklist (WCAG-oriented)

G5) Image/media optimization strategy




PHASE H — Delivery Plan & Execution

H1) 4-phase roadmap with milestones

H2) Sprint breakdown (2-week cadence)

H3) Dependencies and critical path

H4) Risk register + mitigation

H5) Definition of Done per phase




PHASE I — QA Gate (Self-Evaluation + Forced Rewrite)

Score each dimension from 0-10:

- Strategic depth

- Design originality

- Business alignment

- Modularity

- SEO readiness

- RTL quality

- Implementation readiness

- Conversion strength




If any score < 9:

- You MUST rewrite weak sections before finalizing.

- Show “Before vs After improvements” for revised sections.




# 3) OUTPUT RULES

- Use explicit headings and tables where useful.

- Be specific, avoid vague advice.

- No filler.

- No “it depends” without decision criteria.

- Provide directly usable artifacts.




# 4) FINAL MANDATORY ARTIFACTS

At the end, output these 7 artifacts:

1) Executive One-Pager

2) Homepage Section Spec Sheet

3) Copy Pack (FA + EN structure)

4) Design Token Proposal

5) Panel Architecture Map

6) AI Agent Blueprint

7) 90-Day Implementation Plan




Now execute with maximum rigor and creativity.
